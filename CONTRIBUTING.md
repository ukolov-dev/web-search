# Участие в разработке

Создавайте ветку для отдельной задачи и pull request с описанием проблемы, изменения и проверок. Сохраняйте точные цитаты, проверки URL/DNS/IP/редиректов и ограничения бюджета. Не обходите блокировки источников и не сбрасывайте накопленное состояние отказов ради повторной попытки.

Перед PR выполните `cargo fmt --check`, `cargo test --locked` и `cargo clippy --locked --all-targets -- -D warnings`. Живые и модельные пробы запускайте только отдельно; укажите расходы, ошибки и непроведённые проверки. Рост среднего качества не компенсирует новые ложные или неподтверждённые ответы.

Не добавляйте ключи, cookies, локальные настройки, пользовательские данные, кэши или сырые корпуса. Изменение лицензии обсуждается отдельно с владельцем.
