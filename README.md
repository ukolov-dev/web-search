# web-search

Локальный поисковый MCP-сервер на Rust: поиск страниц, обнаружение источников, извлечение текста и экспериментальное исследование с точными цитатами.

**Статус: experimental / 0.1.0.** Репозиторий содержит рабочий прототип и проверяемые результаты исследований. Общая квалификация поиска и production readiness ещё не завершены. Результаты отдельных экспериментов не являются гарантией достоверности ответов.

## Возможности

| Инструмент | Назначение |
| --- | --- |
| `search` | Поиск страниц с явным выбором источника |
| `discover` | Обнаружение и отбор ссылок |
| `extract` | Извлечение текста публичных страниц |
| `ranked_search` | Экспериментальное ранжирование с моделью |
| `research` | Ограниченное исследование: утверждения, цитаты, пробелы и аудит |

Runtime — Rust. Node.js и Python используются только в исследовательских скриптах. MCP работает через stdin/stdout; отдельный серверный порт не открывается.

## Быстрый старт

Нужны Rust/Cargo и доступ к crates.io для первой сборки. Версия toolchain закреплена в [rust-toolchain.toml](rust-toolchain.toml).

```sh
git clone https://github.com/ukolov-dev/web-search.git
cd web-search
cargo build --release --locked
./target/release/web-search mcp
```

Процесс `mcp` ожидает JSON-RPC от MCP-клиента. Настройка клиента:

```json
{
  "mcpServers": {
    "web-search": {
      "command": "/absolute/path/to/web-search/target/release/web-search",
      "args": ["mcp"]
    }
  }
}
```

`search`, `discover` и `extract` не требуют модельного ключа. Для модельных инструментов провайдер задаётся доверенными параметрами запуска. Ключ хранится в отдельном локальном файле:

```sh
./target/release/web-search mcp \
  --openrouter-key-file /absolute/path/to/openrouter.key \
  --model YOUR_MODEL_ID \
  --evidence-memory \
  --source-state .cache/source-state.json \
  --cache-db .cache/web-search.sqlite
```

Вместо OpenRouter поддерживаются локальные настройки oMLX через `--omlx-settings`. Локальный Qwen reranker подключается через `--reranker-settings` вместе с `--evidence-memory`. Веса не входят в репозиторий и автоматически не скачиваются. При внешнем провайдере вопросы и выбранные фрагменты отправляются этому провайдеру.

## Проверки

```sh
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
```

Обычные тесты не обращаются к публичным источникам. Не запускайте весь набор `--ignored`: он содержит живые поисковые и модельные пробы. Их следует выбирать по одному после чтения соответствующего отчёта.

## Ограничения

- Поиск зависит от доступности внешних сайтов; CAPTCHA и блокировки не обходятся.
- `research` ограничен двумя формами запроса, четырьмя SERP, четырьмя чтениями, четырьмя Qwen-вызовами, шестью генерациями и 180 секундами.
- Точная цитата не гарантирует семантическую поддержку утверждения. Известные ошибки и неполные ответы сохранены в отчётах.
- Выбор RFC-разделов со связанными исключениями пока существует только в тестовых экспериментах.
- Сырые корпуса, кэши, модельные ключи, локальные конфиги и личный контекст разработки не публикуются. Не все исторические эксперименты воспроизводятся без отдельно сохранённых корпусов.
- Проверки на macOS не заменяют проверку Linux, нагрузочного режима или серверного развёртывания.
