# Живой тест новостей Воронежа: протокол

Дата пользовательского календаря: 3 ноября 2026, Europe/Moscow. Это ограниченный пользовательский тест, без изменения runtime. Вопрос: выдаёт ли текущий локальный MCP полезные свежие новости города, и улучшает ли ranked_search результат относительно простого search?

Запросы до первого сетевого обращения:

1. n01: `новости Воронежа сегодня 3 ноября 2026`
2. n02: `Воронеж перекрытие дорог транспорт ноябрь 2026`
3. n03: `Воронеж культурные события мероприятия 3 4 ноября 2026`

Один MCP-процесс с текущим release, явными OpenRouter DeepSeek и локальным Qwen, evidence-memory opt-in. Для каждого запроса: search Seznam, search Naver (по 10), затем ranked_search (10). Итого до 12 поисковых обращений, до 9 генеративных вызовов, до 12 Qwen/чтений внутри ranked_search. Между инструментами не менее 2 секунд. Не запускать Bing/DDG с прежними блокировками. После новой блокировки не перезапускать источник/хост ради повторов. До 8 дополнительных extract URL уникально, по одному чтению URL; без обхода ограничений. Встроенный веб-поиск исследователя отдельно: те же 3 запроса, до 8 открытий страниц. Обнаруженные позже уточнения сохраняются как диагностические, не заменяют исходные запросы.

Оценка top-10 вручную: 0 чужая тема/география; 1 фон, недатированная/старая/неполная карточка или рубрика; 2 конкретная подходящая публикация с наблюдаемой датой/периодом. Для n01 свежесть 1–3 ноября 2026, без будущих дат; для n02 сведения/ограничения, действующие в ноябре 2026; для n03 конкретное мероприятие в Воронеже 3–4 ноября 2026. Областной материал без связи с городом отдельно, не автоматически grade2. Неизвестная дата не считается свежей. У grade2, основанной только на SERP, явно сохраняется граница проверки. Даты публикации и события разделяются. Один и тот же URL не увеличивает число уникальных результатов. Синдикации одного сюжета отмечаются.

Считать: grade2@10 / фактически возвращённые (также доля от 10 мест), конкретные статьи против рубрик, подтверждённые свежие даты, прямые неверные метки/unknown, ошибки и бюджеты. Recall по всему вебу не измеряется. Сравнение встроенного веб-поиска качественное, поскольку его источники/ранжирование/покрытие отличаются; находки не подаются продукту. Search и ranked_search живые, сырьё не гарантированно идентично; эффект одного reranker из этого опыта не выделяется.

Все ответы MCP и встроенного поиска сохраняются в runs/voronezh-news-2026-11-03 до последующих обращений. Итоговый отчёт в doc с выводом, ошибками, примерами и ограничениями. Условие остановки: выполнить три исходных запроса, проверить существенные даты/публикации и сравнить все ветки; не дорабатывать продукт в рамках теста. Это не новая квалификация пилота и не A/B v9/v10.

Дополнение после основной серии, до четвёртого запроса: все три дали 0 direct и0 подходящих датированных статей; нельзя исключить влияние длинной формы с годом. Отдельная диагностическая проба n00 `новости Воронежа` — точная короткая пользовательская фраза: те же search Seznam/Naver и ranked_search, до4 поисковых/3 генеративных/4 Qwen/4 внутренних чтений дополнительно. Оценка свежести1–3 ноября остаётся, но без утверждения, что в n00 дата была обязательной частью самого запроса. Эта проба не заменяет исходную серию. Один новый MCP-процесс допустим только после проверки, что основная серия не получила source/host block; перезапуск не применяется для обхода блокировки. Дополнительно до1 discover по уже найденной главной РИА идо2 extract найденных им статей: отдельный агентский путь search→discover→extract. Находки reference для такого пути не используются. Его результат не засчитывается ranked_search. Основные extra extract использованы7/8, новые2 отдельно; всего extra не более10 URL и1discover. Это диагностическое расширение, а не preregistered основная оценка.

После discover/extract: обе статьи РИА прочитаны продуктом, но extract не сохраняет год публикации в date field (в тексте только2/3 ноября). Разрешённые2 дополнительных открытия этих же URL встроенным веб-инструментом — только проверка даты, без поиска новых URL и без изменения основной оценки. Если год не наблюдаем, он останется неизвестным.
