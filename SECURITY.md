# Сообщение об уязвимости

Не публикуйте ключи, cookies, персональные данные или рабочие эксплойты с чувствительными деталями в обычных issues. Используйте GitHub Private Vulnerability Reporting, если он включён в репозитории; иначе запросите у владельца приватный канал, не раскрывая подробности.

Воспроизводимый отчёт должен указывать версию, минимальный вход и затронутую границу доверия. Проект экспериментальный; гарантированного срока ответа или production-поддержки пока нет.
